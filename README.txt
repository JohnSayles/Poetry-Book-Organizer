Hello, I made this program for personal use a while ago, but I decided to put it on Github in case anyone else might want it.

It basically allows you to create a poetry book with chapters and poems. You are free to move/add/delete/rename the poems and chapters wherever/whenever you want. You can export the poetry book to rtf when you are done. It will come formatted in my preferred poetry book structure. You can also import the rtf as long as the format structure is the same. The poem books are automatically stored in your documents section. BTW, it is not very pretty. I used javax swing for this because it was originally for personal use.

In the future, I might add export customization, and have the import accept more types of formats. I also might move it from something other than javax swing. I personally have found this app very useful, and hope you enjoy.
